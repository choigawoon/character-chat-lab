# 세계 파일 규약 — content/worlds/<id>.json

세계 하나 = 파일 하나. 세계관 · 인물 · 상황극은 미리 최상위 모델이 써서 넣고, 대화 중에는 작은 모델(E2B · E4B)이 이 글을 읽고 연기만 한다.
작은 모델이 읽기 쉽게 쓴다 — 짧은 문장, 목록, 숫자 · 이름은 정확히, 서로 어긋나는 설정 금지.

```jsonc
{
  "id": "hp-malfoy",                       // 파일 이름과 같다 · 영문 소문자 · '-'
  "title": "해리 포터 AU — 여자가 된 말포이",   // 화면 제목
  "source": "J.K. 롤링 『해리 포터』의 팬픽 설정(AU)",   // 원작 표기. 원작 문장은 옮기지 않는다
  "genre": ["판타지", "학원", "TS"],
  "cover": { "emoji": "🐍", "color": ["#1f6b4a", "#c9d6cf"] },
  "summary": "카드에 보이는 소개 1~2문장",
  "bible": "세계관 — 모델에 들어가는 글. 600~1,200자. 때 · 곳 · 세계의 규칙 · 이번 이야기의 비틀기(원작과 다른 점) · 분위기",
  "lore": [                                 // 로어북 8~15개 — 대화에 keys 중 하나가 나오면 그 턴에만 맥락에 들어간다
    { "keys": ["스네이프", "마법약 교수"], "text": "1~2문장 사실" }
  ],
  "characters": [                           // 2~5명
    {
      "id": "malfoy", "name": "드레이코 말포이", "emoji": "🐍", "color": ["#1f6b4a", "#c9d6cf"],
      "sheet": "인물 시트 300~700자 — 나이 · 외모 · 성격 · 말투 규칙(호칭 · 어미) · 관계 · 비밀 · 모르는 것(알면 안 되는 것)",
      "speech": ["말투 예시 대사 1", "2", "3"]   // 3~5개 · 그 인물만의 말버릇이 보이게
    }
  ],
  "scenarios": [                            // 세계마다 2~3편
    {
      "id": "hp-malfoy-1",                  // <세계 id>-<번호>
      "title": "상황극 제목",
      "hook": "카드 한 줄 — 무엇이 벌어졌나",
      "you": "사용자가 맡는 역할 — 이름 + 한 줄 (예: '해리 포터 — 그리핀도르 5학년')",
      "lead": "malfoy",                      // 모델이 주로 연기하는 인물 id
      "cast": ["malfoy", "crabbe"],          // 이 장면에 나올 수 있는 인물 id (lead 포함)
      "setting": "지금 장면 200~400자 — 때 · 곳 · 직전에 일어난 일 · 사용자가 처한 처지",
      "opening": "첫 장면 300~600자 — 진행자 서술(*별표*) + lead 의 첫 대사. 사용자의 대사 · 행동은 쓰지 않는다. 사용자가 바로 반응할 거리로 끝낸다",
      "goal": "사용자에게 보여 줄 '이 상황극에서 해 볼 수 있는 것' 1~2문장",
      "director": [                          // 숨은 전개 3~5개 — 모델만 본다. 사용자가 이끌지 않으면 차례로 꺼낼 사건 · 반전 · 가능한 결말
        "1. …", "2. …"
      ],
      "pinned": ["처음부터 기억할 사실 3~6개 — 짧게"]
    }
  ]
}
```

## 쓰는 규칙

- 한국어. 사람 이름 · 지명은 국내 번역판에서 널리 쓰는 표기(예: 헤르미온느 그레인저, 곽정 · 황용, 아쿠아 · 메구밍).
- **원작 문장을 옮기지 않는다** — 줄거리 · 설정 · 이름만 빌려 새로 쓴다. 대사 예시도 새로 쓴다.
- **전연령** — 성적 묘사 · 잔혹 묘사 없음. 원작이 무거운 주제(가난 · 폭력 · 죽음)를 다루면 그 무게는 남기되 장면은 절제한다.
- 사용자가 개입해 결말을 바꿀 수 있게 연다 — director 에 "사용자가 ○○하면 △△" 같은 갈림을 1~2개 넣는다.
- opening 은 사용자 차례로 끝낸다(질문 · 선택 · 긴장).
- 분량은 위 범위를 지킨다 — 작은 모델의 맥락 창은 짧다. 한 상황극을 고르면 bible + 그 상황극 cast 시트 + setting + director + pinned 가 함께 들어가므로 합쳐서 4,000자 안쪽이 좋다.
